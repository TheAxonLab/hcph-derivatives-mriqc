The MRIQC derivatives of the HCPh dataset have been ported to the repository [hcph-mriqc](https://github.com/TheAxonLab/hcph-mriqc).
The derivatives there have been extracted with a more recent version of MRIQC.
The derivatives of the MRIQC version 24.0.0 extracted from the reliability subset of the data are still available at https://mriqc.s3.amazonaws.com/index.html#hcph/
